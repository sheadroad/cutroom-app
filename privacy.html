cutroom 개인정보처리방침

시행일: 2026-11-13

cutroom은 운영자 한 사람이 자신의 유튜브 채널을 관리하려고 쓰는 개인용 도구입니다.

1. 수집하는 정보

Google OAuth로 운영자 본인 계정에 로그인하면, YouTube Data API와 YouTube Analytics API를 통해 운영자 본인 채널의 영상 정보와 통계에 접근합니다. 다른 사람의 개인정보는 수집하지 않습니다.

2. 사용 목적

운영자 본인 채널에 영상을 올리고, 제목·설명·태그·공개 예약을 설정하고, 채널 통계를 확인하는 데에만 씁니다.

3. 저장과 공유

로그인 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 정보를 제3자에게 판매하거나 공유하지 않습니다.

4. 접근 해제

언제든 Google 계정 권한 설정에서 cutroom의 접근을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

5. 관련 약관

cutroom은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

Privacy Policy (English)

Effective 2026-11-13. cutroom is a private tool one operator uses to manage the operator's own YouTube channels. When the operator signs in with Google OAuth, it accesses the operator's own channel videos and analytics through the YouTube Data API and YouTube Analytics API, only to upload videos, set titles, descriptions, tags and scheduled publishing, and read analytics. No other person's data is collected. Tokens are stored only on the operator's computer and are not sent to any server or shared with third parties. Access can be revoked at any time at Google Account permissions. cutroom uses YouTube API Services; the YouTube Terms of Service and Google Privacy Policy apply. Contact: GitHub issues.
