cutroom

cutroom은 운영자가 자신의 유튜브 채널(왈왈한자, 네뮤)에 올릴 영상을 만들고 관리하는 개인용 제작 도구입니다. 외부 사용자에게 제공하는 서비스가 아닙니다.

cutroom is a private production tool the operator uses to make and manage videos for the operator's own YouTube channels. It is not offered to other users.

YouTube 데이터 사용 / Use of YouTube data

  • 운영자 본인 채널에 영상 업로드, 제목·설명·태그·공개 예약 설정 / Upload videos to the operator's own channels and set titles, descriptions, tags and scheduled publishing.
  • 운영자 본인 채널의 조회수·시청 지속 등 통계 확인 / Read analytics for the operator's own channels.
